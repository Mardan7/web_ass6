jQuery is a JavaScript library that makes selecting HTML elements, handling events and creating effects easier. The $ symbol is a shortcut for jQuery.

$("#title") selects an ID, $(".note") selects a class, and $("p") selects all paragraph elements.

.text() inserts plain text. .html() interprets HTML tags. I use .text() for the form preview so user input is displayed as text.

A click handler finds the selected answer. Other answers close with .slideUp(), and the selected answer opens or closes with .slideToggle(). The button's aria-expanded attribute tracks its state.

Several .animate() calls on the same element run in sequence by default. Multiple properties in one .animate() call change together. The duration is measured in milliseconds.
